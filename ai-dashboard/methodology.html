How the tracker works

Every number on the tracker comes from one data file, refreshed each morning before 07:00 AEST.

Scores

The main capability score is the Artificial Analysis Intelligence Index, a composite of ten hard evaluations run independently on every model. Where available we also show the Epoch Capabilities Index (ECI). Benchmark rows taken from a company's own launch table are marked † because they are not independently verified, and different test harnesses can move a score by several points.

Open vs closed

"Open" means the model's weights can be downloaded and run by anyone under the stated licence. The frontier lines show the best score achieved so far by each group; they only ever rise.

Capability forecast

The closed frontier is projected forward at a low, central and high rate in index points per month, fitted to recent releases. The open frontier is projected as the closed frontier delayed by the open-model lag (Epoch AI measures roughly four months on average; on this index we currently use 4–7 months). A further 1–3 months is added before an equivalent model runs on a desktop costing under AUD 50k. Milestone dates combine the fastest growth with the shortest lag for the early end of each range, and the slowest with the longest for the late end.

Task length

METR measures how long a task, timed on a skilled person, an AI agent can complete with 50% reliability. We project from the last measured model with a doubling time between four and seven months. METR's current test suite is unreliable above about 16 hours and its public page has not been updated since 8 September 2026, so recent values are projections, not measurements.

Subscriptions vs API

Plan prices and included API credits are published by the vendors. How much work a plan allows is not: Anthropic and OpenAI describe session and weekly limits without token budgets. We therefore show estimate ranges for each plan's API-equivalent value and its capacity in agent-hours per week, labelled with a confidence level. One agent-hour is assumed to use 3M cached input tokens, 0.3M fresh input tokens and 0.12M output tokens; multiplying by a model's list prices gives its API cost per agent-hour. The cost comparison adds API-priced overflow when usage exceeds a plan's mid-estimate capacity, net of any included API credit.

Solo engineer + AI multiplier

A task-weighted estimate of how much more digital engineering work (design, analysis, code, documents, admin) one skilled engineer produces with a frontier model, grown by a modest monthly rate as models improve. Hands-on hardware work gets almost no speed-up and is excluded from this headline figure.

Updates

A scheduled job researches new releases, prices and measurements, edits the data file under strict rules (sources required, unknown values left blank, history never deleted), runs a validator, archives a dated snapshot and publishes. Material changes are listed at the foot of the tracker.
